# 🛠️ Creating Your Alfajores iOS Project

The project file I created had some issues. Let's create it properly using Xcode!

## 📱 **Step-by-Step: Create New Project**

### 1. **Open Xcode**
```bash
open /Applications/Xcode.app
```

### 2. **Create New Project**
- When Xcode opens, click **"Create a new Xcode project"**
- Or go to **File → New → Project**

### 3. **Choose Template**
- Select **"iOS"** tab at the top
- Choose **"App"** template
- Click **"Next"**

### 4. **Configure Your Project**
Fill in these details:
- **Product Name**: `AlfajoresApp`
- **Team**: Select your Apple ID (sign in if needed)
- **Organization Identifier**: `com.bruno.alfajores` (change "bruno" to your name)
- **Bundle Identifier**: Will auto-fill as `com.bruno.alfajores.AlfajoresApp`
- **Language**: **Swift**
- **Interface**: **SwiftUI**
- **Use Core Data**: ✅ **Check this box** (IMPORTANT!)
- **Include Tests**: ✅ **Check this box**

Click **"Next"**

### 5. **Choose Location**
- Navigate to: `/Users/bruno/Documents/alfajores/`
- Click **"Create"**

## 🎯 **After Project is Created**

Xcode will create a working project. Then I'll help you add all the alfajores functionality to it.
