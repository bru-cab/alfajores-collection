
# 🆓 Opciones de Backend 100% GRATIS

## 🥇 **Render.com (Recomendado)**

### ✅ Ventajas:
- 750 horas gratis por mes (suficiente)
- Se "duerme" pero despierta rápido
- Fácil de usar
- Base de datos incluida

### 📋 Pasos:
1. Ve a https://render.com
2. "New" → "Web Service"
3. Connect GitHub o Upload files
4. Sube la carpeta `backend/`
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `python app.py`
7. ¡Deploy!

### ⚙️ Configuración:
- Environment: Python 3.10
- Plan: Free (0$)
- Auto-deploy: Yes

---

## 🥈 **PythonAnywhere (Muy fácil)**

### ✅ Ventajas:
- 100% gratis
- No se duerme
- Interface web simple
- Incluye editor online

### 📋 Pasos:
1. Ve a https://pythonanywhere.com
2. Crea cuenta gratuita
3. Upload files en el dashboard
4. "Web" → "Add new web app"
5. Choose "Flask"
6. Point to your `wsgi.py`
7. ¡Live!

### ⚙️ URL final:
`https://yourusername.pythonanywhere.com`

---

## 🥉 **Cyclic.sh (Nuevo y bueno)**
